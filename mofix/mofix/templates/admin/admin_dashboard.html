🔌 Admin API Endpoints

All endpoints require a logged-in superuser session (or session cookie). Responses are JSON. Base URL: /admin-api/

GET /admin-api/ — Platform overview stats GET /admin-api/users/ — List users (search, filter, paginate) GET /admin-api/users/<id>/ — User detail + payment history PATCH /admin-api/users/<id>/ — Update user fields POST /admin-api/users/<id>/action/ — activate | deactivate | reset_plan | change_plan GET /admin-api/revenue/ — Revenue stats + transaction log GET /admin-api/tips/ — List weekly tips POST /admin-api/tips/ — Create a new tip PATCH /admin-api/tips/<id>/ — Update tip DELETE /admin-api/tips/<id>/ — Delete tip GET /admin-api/forecasts/ — List weekly forecasts POST /admin-api/forecasts/ — Create forecast PATCH /admin-api/tips/<id>/ — Update forecast DELETE /admin-api/forecasts/<id>/ — Delete forecast GET /admin-api/analytics/ — Aggregated analytics data GET /admin-api/predictions/ — All predictions (filterable) GET /admin-api/activity/ — Recent activity log GET /admin-api/settings/ — Platform configuration
